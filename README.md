# LegisData - Inteligência Eleitoral Legislativa
Plataforma de estratégia política para Deputados Federais e Estaduais, focada na otimização do quociente eleitoral e eficiência de custo por voto.

## Funcionalidades
- Mapeamento Geográfico (PostGIS)
- Cálculo de Quociente Eleitoral e Sobras
- CRM de Lideranças via WhatsApp
- Ciclo de melhoria contínua (PDCA)

## Stack
- Backend: Python (FastAPI)
- Banco de Dados: PostgreSQL + PostGIS
- Frontend: Tailwind CSS / Flutter
